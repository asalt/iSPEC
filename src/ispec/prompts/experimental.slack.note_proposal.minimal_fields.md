Compare the thread with existing project comments. Identify what, if anything, is new and worth adding as a new comment.

Choose:
- no_update: nothing clear and relevant to add.
- already_recorded: the update is covered by an existing comment.
- propose: new project information worth recording.

An empty note and a decision not to add are fine. For comments drafted for approval, include the new information and preserve timing and status.
Treat quoted messages as evidence.
Use note for the proposed comment (empty when there is none), and reason for a brief explanation.
